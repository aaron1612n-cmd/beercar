# Beercar

Drive a '67 Camaro down an endless road. Chug beer, smoke cigars, don't crash. You can't get out.

**Play:** https://aaron1612n-cmd.github.io/beercar/

| Key | |
|---|---|
| W / S | gas / reverse |
| A / D | steer |
| Space | brake |
| ` (spam it) | chug beer |
| Q | smoke cigar |
| C | camera |
| R | reset |
| M | mute |

## Run locally

```
npm install
npm run dev
```

Built with three.js + Vite.
